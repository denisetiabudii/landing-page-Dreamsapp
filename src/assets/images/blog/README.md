# Foto sampul blog

Taruh foto sampul artikel di folder ini. Tidak perlu mengubah kode:
nama file harus sama dengan slug artikel, ekstensi `.webp`.

| Artikel | Nama file |
|---|---|
| Apa Itu Analisis RFM dan Cara Memakainya untuk Memahami Donatur | `apa-itu-analisis-rfm-donatur.webp` |
| Cara Mengelola Data Donatur Lembaga Sosial agar Tidak Tercecer | `cara-mengelola-data-donatur-lembaga-sosial.webp` |
| Mengapa Bukti Donasi Penting untuk Transparansi Lembaga Sosial | `bukti-donasi-transparansi-lembaga-sosial.webp` |

Spesifikasi:

- Ukuran **1200 × 630 piksel** (rasio 1,91 : 1), format **WebP**, maksimal **150 KB**.
- Objek utama di tengah gambar (kartu daftar artikel memotong sedikit di tepi).
- Jangan taruh teks penting di tepi gambar.
- Sebelum foto ada, kartu menampilkan latar gradien berwarna (placeholder).

Menambah artikel baru: tambahkan isinya di `src/data/blogPosts.js`
dan daftarkan halamannya di `src/routes.js`.
